# NeuroLog 🧠

A modern productivity and mental wellness tracker built using **HTML, CSS, and JavaScript**.  
NeuroLog helps users track habits, tasks, moods, water intake, gratitude, journals, and productivity analytics — all in one clean dashboard.

# ✨ Features

## 📝 Daily Journal
- Write and save daily journal entries
- Persistent storage using LocalStorage
- Journal history viewer by date

## 🙏 Gratitude Section
- Save daily gratitude notes
- Dedicated gratitude card with scroll support

## ✅ Task Manager
- Add and complete daily tasks
- Dynamic productivity tracking
- Persistent task storage

## 📊 Productivity Analytics
- Interactive charts using Chart.js
- Monthly productivity tracking
- Mood trend analysis
- Heatmap-based consistency tracker

## 🔥 Habit Tracker
- Track multiple daily habits
- 30-day streak tracking table
- Habit completion visualization

## 💧 Water Intake Tracker
- Interactive water glass UI
- Daily hydration tracking

## 😊 Mood Tracker
- Mood selection system
- Mood analytics and visualization
- Emotional trend tracking

## 🌙 Dark Mode
- Smooth dark/light theme switching
- Theme persistence using LocalStorage

## 📱 Responsive Design
- Mobile-friendly dashboard layout
- Responsive cards and navigation
- Scrollable responsive tables
